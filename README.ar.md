# Prism

**الضوء ينحني إلى عمل.**

شعاع واحد يدخل، كل الأطياف تخرج. Prism هو محطة عمل ذكاء اصطناعي محلية أولاً
ومستقلة عن النموذج، يكسر أسئلتك عبر الوكلاء والدفاتر والملفات والأرقام
والتقارير والمراجعة — كل واحد منها لون مختلف لنفس الفكر.

مبني بـ Tauri 2 و React و MCP ومهارات الوكلاء والمخرجات القابلة للتكرار.
يعمل على macOS و Windows و Linux.

## ما هو Prism؟

Prism هو محطة عمل ذكاء اصطناعي لسطح المكتب. تطرح سؤالاً. Prism يمرره عبر
جميع أدواتك — الوكلاء والدفاتر والملفات والمتصفحات والآلات البعيدة — ويعيد
لك ليس مجرد إجابة، بل الطيف بأكمله: الأرقام والكود والتقارين والأصل
والمسار الدقيق للتفكير.

**مدخل واحد. كل الأطوال الموجية.**

- سؤال بحثي يصبح مراجعة أدبية وتجربة وشكل وورقة بحثية
- موجز تصميم يصبح نماذج أولية وتصديرات وتقديمات
- سؤال بيانات يصبح تحليلاً ودفاتر ومخططات وتقارير
- مهمة برمجة تصبح وكلاء وأدوات واختبارات ووثائق

كل شيء محلي. كل شيء لك. كل شيء قابل للتتبع.

---

## لماذا "Prism"؟

المنشور يأخذ شعاعاً من الضوء ويكشف أنه كان دائماً مصنوعاً من ألوان عديدة.
Prism يأخذ سؤالاً ويكشف أنه كان دائماً مصنوعاً من مهام عديدة — كل واحدة
طول موجي مختلف لنفس الفكر، كل واحدة تنتج شيئاً حقيقياً.

## الميزات

### وكلاء مستقلون ينتجون مخرجات حقيقية
ليس مجرد دردشة. كل إجراء من الوكيل ينتج ملفات قابلة للفحص — أشكال وتقارير
ودفاتر — مرتبطة بالمدخلات والبيئة والمحادثة الدقيقة التي أوجدتها.

### كل شيء قابل للتتبع
تتبع الأصل يربط كل مخرج بمصدره. افتح أي مخرج وانظر السكريبت والبيانات
والمخرجات النموذجية والمحادثة التي أوجدته.

### محلي أولاً بشكل افتراضي
جلساتك وبياناتك وأصل البيانات ودفاترك وسجلات التشغيل تعيش على جهازك.
لا شيء يغادر إلا إذا أردت ذلك.

### مستقل عن النموذج
أحضر نموذجك الخاص. وقت التشغيل يدعم أي مزود — OpenAI، Anthropic، النماذج
المحلية، نقاط النهاية المخصصة. المهارات وخوادم MCP تبقى قابلة للتوصيل.

### اصل إليه من أي مكان
بوابة مدمجة تقدم واجهة سطح المكتب الحقيقية للمتصفح على شبكتك المحلية أو
هاتفك. ابدأ تشغيلاً على مكتبك، تحقق من النتائج من هاتفك.

### قِض متصفحك الخاص
يمكن للوكيل التحكم في Chrome الخاص بك — الملف الشخصي وتسجيلات الدخول
سليمة — أو استخدام متصفح خاص معزول.

### خطط قبل التصرف
`/plan` يضع خطة تنفيذ. `/goal` يحدد الهدف والقيود ومعايير القبول.
ثم ينفذ الوكيل.

### اعمل على عدة أشياء في وقت واحد
بلاطات اللوحات جنباً إلى جنب. شغل نماذج مختلفة في كل منها. اسحب للإرساء.
شاشات مستقلة لمشاريع مختلفة.

## حلقة البحث

المنهج العلمي الكامل، كسلسلة مهارات:

| المرحلة | ماذا تفعل | المخرجات |
| --- | --- | --- |
| استكشف | حول اتجاه عام إلى مواضيع محددة | مصفوفة المواضيع، مسح الأدب المسبق |
| مسح | ابحث ولخص الأدبيات | 6–20 صفحة PDF، 60+ اقتباسات حقيقية |
| تجربة | صمم ونفذ التجارب | كود، نتائج، أشكال، أصل |
| اكتب | صغ ورقة بحثية | 8–14 صفحة PDF، 200+ اقتباسات، أشكال |

كل مرحلة قائمة بذاتها. شغلها بشكل فردي أو دع المهارة الوصفية تربطها من
طرف إلى طرف.

## التثبيت

حمّل من [صفحة الإصدارات](https://github.com/bmo1177/Prism/releases/latest).

| المنصة | التنسيق |
| --- | --- |
| macOS | `.dmg` / `.app` (Apple Silicon و Intel) |
| Windows | `.exe` / `.msi` |
| Linux | `.deb` / `.rpm` / AppImage |

```bash
# Linux .deb
sudo apt install ./Prism_*.deb

# Linux .rpm
sudo rpm -i Prism-*.rpm

# AppImage
chmod +x Prism_*.AppImage
./Prism_*.AppImage
```

## البناء من المصدر

المتطلبات: Node.js ≥ 20، pnpm 9، سلسلة أدوات Rust، تبعيات نظام Tauri.

```bash
git clone https://github.com/bmo1177/Prism
cd Prism
pnpm install

# احصل على sidecars والمهارات المجمعة
bash scripts/dev/fetch-opencode.sh
bash scripts/dev/fetch-uv.sh
bash scripts/dev/fetch-skills.sh

# تطوير
pnpm --filter @ai4s/desktop tauri dev

# بناء
pnpm --filter @ai4s/desktop tauri build
```

## تخطيط المستودع

| المسار | الغرض |
| --- | --- |
| `apps/desktop/` | غلاف سطح المكتب Tauri + React |
